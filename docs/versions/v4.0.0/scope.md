# V4.0.0 版本范围

## 结论

**V4.0.0** 交付「计划—任务—周月填报—领导监督」经营管理台：演示范围为总经理 + 生产/设备/安监/市场四部门；计划双维（年→月→周 × 公司→部门）；任务双维（结构化周任务项 + 文本上周总结/下周概述）；总经理宏观一表为 Excel 多列；PC 原型已确认生成。

## 范围清单（P0）

| 一级 | 二级 | 说明 |
| --- | --- | --- |
| 工作台 | 待办页 | 周填报/月填报/任务/催办/例会待办 |
| 总经理 | 经营总台账 | 公司整体计划下达、查看、完成、关联任务 |
| 总经理 | 整体计划与任务监督 | 延期统计、催办 |
| 总经理 | 宏观一表 | Excel 多列；默认部门×月；未拆月不展示 |
| 总经理 | 周报视角 | 上周复盘 + 本周/下周概述汇总 + 任务项统计 |
| 部门长 | 部门台账 / 任务下达 / 月填报 | 本部门；可派本部门人及关联部门长 |
| 全员 | 我的计划与任务 / 周填报 | 任务项（数量/状态/耗时小时整数）+ 文本概述 |
| 公共 | 年/月/周计划、部门年度重点、周例会待办 | 三级计划；例会待办独立对象 |
