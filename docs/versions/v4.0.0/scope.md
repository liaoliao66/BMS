# V4.0.0 版本范围

## 结论

**V4.0.0** 交付「公司计划 → 部门计划树 → 任务执行 → 周月报 → 催办/督办/考核」经营管理台。演示范围：总经理 + 计划管理员 + 生产/设备/安监/市场四部门；计划为**无限层级树**（不再做年/月/周计划实体）；日常抓落实以**落实驾驶舱**为主，辅以三张经营主表；PC 原型为事实源。

## 范围清单（P0）

| 一级 | 二级 | 说明 |
| --- | --- | --- |
| 工作台 | 落实驾驶舱 | 总经理日清：KPI、重点任务红黄灯、催办篮子、例会/部门完成度 |
| 工作台 | 我的待办 | 部门长/员工/计划管理员：按模块处理周报/月报/任务/督办/催办 |
| 经营主表 | 公司计划表 | 公司整体目标下达、进度手填、起止日 |
| 经营主表 | 部门计划表 | 四部门计划树只读联查（总经理/计划管理员） |
| 经营主表 | 整体任务表 | 全公司任务监督、催办入口 |
| 计划 | 计划管理/计划总控 | 部门长本部门树；计划管理员全量；含导入 |
| 计划 | 计划/任务导入 | CSV 模板→预览校验→写入 |
| 计划 | 计划详情 | 大弹窗：公司/部门计划详情与变更 |
| 任务 | 任务管理/任务总控 | 计划任务 + 临时任务；下达/自建；子任务 |
| 闭环 | 任务周报 / 任务月报 | 按「用户×公司计划×周期」文本+附件；部门长可编 |
| 闭环 | 任务督办 | 计划外督办（原周例会待办并入）+ 周例会纪要（计划管理员维护） |
| 闭环 | 绩效考核 | 按部门/人员完成率；红区置顶；可催办 |
| 闭环 | 经营一表 | L1→L2→L3 合成展开（按需，本版 P0） |
| 更多 | 数据分析 | 原宏观一表能力，按需入口 |

## 不在本版

| 项 | 说明 |
| --- | --- |
| 年/月/周计划实体 | 改为无限层级部门计划树 |
| 日计划 | 不做 |
| 经营数字结构化指标引擎 | 进度与完成以手填/文本为主 |
| 消息中心 / 审批流 / 权限配置页 | 走内部平台；原型用角色切换模拟 |
| 综合/财务/智慧港口演示组织 | 不进种子 |
