# V1.1.0 版本范围（任务转派增量）

## 结论

**V1.1.0** 在 **v1.0.0** 目标 / 计划 / 任务闭环之上，交付 **任务转派**（须留转派记录；发布后禁止在编辑中静默改责任人）。

## 范围清单（相对 v1.0.0 增量 · P0）

| 一级 | 二级 | 说明 |
|------|------|------|
| 任务中心 | 任务转派 | 变更主责责任人；写入只读转派记录；入口：任务清单列表 / 详情（含企微） |
| 任务中心 | 转派记录 | 任务详情「转派记录」分区；只增不改不删 |
| 任务中心 | 编辑约束 | 发布后禁用编辑改责任人，仅可通过转派变更 |

## 继承范围

完整继承 v1.0.0：工作台账 / 周报 / 月报、目标、计划、任务清单、督办、专项、基础配置等。

## 不在 V1.1.0

跨部门转派、经营总览、CRM、合同结算、量化达成、档案、知识库、AI 等。
