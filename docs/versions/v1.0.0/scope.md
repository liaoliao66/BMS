# V1.0.0 版本范围（第一期）

## 结论

**V1.0.0** 仅交付「工作目标 → 计划 → 任务」执行闭环，不包含经营总览、生产作业、CRM、合同结算、档案、知识库、AI。

## 范围清单（P0）

| 一级 | 二级 | 说明 |
|------|------|------|
| 经营台账 | 任务台账 | 部门健康、待跟进/待计划、目标树入口 |
| 经营台账 | 工作周报 | 周/月汇报汇总与较上期对比 |
| 目标计划 | 目标管理 | 年-季-月目标树、健康状态、拆解 |
| 目标计划 | 计划管理 | 计划与关键节点 |
| 任务中心 | 任务清单 | 我的任务、详情填报、附件评论 |
| 任务中心 | 任务督办 | 领导下达督办 |
| 任务中心 | 汇报提醒 | 未填报催填（支撑工作周报） |
| 任务中心 | 专项管理 | 专项归集计划与任务 |
| 系统支撑 | PC壳 / 组织同步 / SSO | 可上线最小系统能力 |
| 基础配置 | 使用范围 | 同步组织人员；开关启用部门/人员；仅启用者填报目标计划任务 |

## 不在 V1

经营总览、生产作业、经营目标值、完整 CRM、完整合同、开票收款、档案、知识库、AI 助手、经营报表等 → **V2.0.0**。
