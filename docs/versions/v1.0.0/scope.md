# V1.0.0 版本范围（精简重做）

## 结论

**V1.0.0** 精简重做：仅服务**公司领导**与**部门负责人**，以「年目标 → 月计划 → 计划节点 → 部门周报」为主链路；清单用年/月/周三 Tab 平铺呈现。  
历史闭环原型已合并至 **v3.0.0**；本版不包含执行人任务、转派、经营总览、CRM、合同等。

## 范围清单（P0）

| 一级 | 二级 | 说明 |
|------|------|------|
| 经营清单 | 年度目标 | 独立菜单；年目标列表与维护；完成%、延期 |
| 经营清单 | 月度计划 | 独立菜单；月计划 + 计划节点；完成%、延期 |
| 经营清单 | 周工作任务 | 独立菜单；按部门填写周报，须关联计划；回写目标%/计划% |
| 目标拆解 | 年→月→节点 | 部门负责人录入年目标，拆月计划，再拆计划节点 |
| 延期管理 | 目标/计划/节点 | 三者均可标注延期并填写延期原因 |

## 角色

| 角色 | 能力 |
|------|------|
| 公司领导 | 查看全公司年/月/周清单与延期原因；不填报 |
| 部门负责人 | 本部门录入拆解、周填报、标延期、更新完成百分比 |
| 执行人员 | **本期不做** |

## 不在 V1.0.0

| 项 | 说明 |
|----|------|
| 执行人任务台 / 督办 / 转派 | 不做 |
| 季目标 / 专项 | 不做；目标到年，计划到月与节点 |
| 工作月报 / 经营总览 / CRM / 合同 / 生产 | 不做 |
| 消息中心 / 审批 / 权限配置页 | 平台能力，本版不设计 |
