# V2.0.0 版本范围（第二期）

## 结论

**V2.0.0** 交付经营一体化能力：以经营总览为汇聚，覆盖生产作业、完整客户 CRM、完整合同与结算、经营目标值，并扩展档案管理、知识库与 AI 智能助手。

## 范围清单

| 一级模块 | 主要内容 | 优先级基线 |
|----------|----------|------------|
| 经营台账 | 经营总览（吞吐/营收/应收/超期/客户明细） | P0 |
| 生产作业 | 作业量按日登记、月季年汇总（客户/客户组） | P0 |
| 经营计划 | 经营目标值（吞吐/营收目标环） | P0 |
| 客户 CRM | 概览、客户、分组、联系人、洽谈、商机、公海等 | P0～P2 |
| 合同管理 | 全生命周期、账期、变更、模板等 | P0～P2 |
| 结算收款 | 开票、收款、应收超期、营收台账 | P0 |
| 档案管理 | 档案库、借阅、归档规则 | P0～P1 |
| 知识库 | 空间、文档、检索 | P0～P1 |
| AI 智能助手 | 经营问答、知识 RAG、业务助理 | P0～P2 |
| 经营分析 | 标准报表、自定义查询 | P1～P2 |
| 系统扩展 | 外部数据同步、企微 H5、消息对接等 | P1 |

## 依赖

依赖 **V1.0.0** 目标/计划/任务主数据与组织权限体系；客户主数据、合同等在本版本建设后反哺总览。
