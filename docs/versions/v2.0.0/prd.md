## 1. 产品概述

### 1.1 产品定位

V2 在 V1「目标 → 计划 → 任务」闭环之上，交付**经营一体化**：以经营总览汇聚吞吐/营收/应收，覆盖生产作业、完整 CRM、合同与结算、经营目标值，并扩展档案、知识库与 AI。

### 1.2 与 V1 边界

| 能力 | 版本 | 说明 |
| --- | --- | --- |
| 工作台账 / 工作周报 / 工作月报 | V1 | V2 总览可链入，不重复建设填报闭环 |
| 目标 / 计划 / 任务 / 专项 | V1 | V2 总览与量化依赖其主数据 |
| 经营总览、合同开票收款、量化达成 | **V2** | 本章及后续章节 |
| 生产 / CRM / 档案 / 知识库 / AI / 报表 | **V2** | 占位，待细化 |

### 1.3 用户角色（增量）

| 角色 | V2 增量职责 | 优先级 |
| --- | --- | --- |
| 公司领导 | 经营总览、合同回款与应收总览 | P0 |
| 商务 / 财务 | 合同、开票、收款登记与对账 | P0 |
| 生产调度 | 作业量按日登记与汇总 | P0 |
| 销售 / 客户经理 | CRM 客户与商机 | P0～P1 |
| 全员 | 知识库检索、AI 问答（按权限） | P1～P2 |

## 2. 结论与范围

### 2.1 结论前置

**v2.0.0 以经营总览为汇聚入口**，补齐合同/开票/收款与经营目标值（量化达成）；生产作业、完整 CRM、档案、知识库、AI、经营分析按占位推进细化。

### 2.2 包含范围（In Scope）

| 模块 | 说明 | 优先级 |
| --- | --- | --- |
| 经营总览 | 合同/开票/收款全量区 + 目标计划任务执行区；部门/项目下钻 | P0 |
| 合同管理 | 已签合同录入与摘要 | P0 |
| 开票记录 | 关联合同登记开票；作废仅改状态 | P0 |
| 收款记录 | 关联合同收款；关联开票选填；本年计划收款独立配置 | P0 |
| 量化达成 | 目标当前值 / 目标值及趋势（V1 未做） | P0 |
| 生产作业 | 作业量按日登记、月季年汇总 | P0 |
| 客户 CRM | 概览、客户、分组、联系人、洽谈、商机、公海等 | P0～P2 |
| 合同扩展 | 账期、变更、模板等全生命周期 | P0～P2 |
| 档案管理 | 档案库、借阅、归档规则 | P0～P1 |
| 知识库 | 空间、文档、检索 | P0～P1 |
| AI 智能助手 | 经营问答、知识 RAG、业务助理 | P0～P2 |
| 经营分析 | 标准报表、自定义查询 | P1～P2 |

### 2.3 不包含范围

| 项 | 说明 |
| --- | --- |
| 消息 / 审批 / 权限配置页 | 仍走内部平台 |
| V1 填报闭环重建 | 不重复建设工作周报/月报/我的任务 |
| 财务总账 / 预算系统 | 非本版默认范围 |

### 2.4 三类场景总览

| 类型 | 要点 |
| --- | --- |
| 正常流程 | 合同建档 → 开票/收款 → 总览看回款与执行 → 量化盯目标值 |
| 边界情况 | 无合同时合同区空态；预收款不关联开票；量化未录入时展示「未填」 |
| 异常兜底 | 未选合同拦截；超额开票/回款强提示可确认；CRM 未就绪时合同客户不可新建 |

## 3. 经营台账 · 经营总览

> 以下由 V1 主 PRD §4.1 迁出。历史文案中的「需关注/风险」以 V1 目标健康两档为准，统一理解为「关注」。

#### 3.1 经营总览


| 维度 | 内容 |
| --- | --- |
| 功能介绍 | 一屏掌握公司经营：目标健康、计划节点、任务执行、部门达成、专项进展、汇报催填、督办与**合同回款**摘要 |
| 前置条件 | 已存在已发布目标；用户具备领导或部门负责人可见范围 |
| 数据权限 | 领导看全公司；部门负责人看本部门及下属专项 |
| 页面跳转 | 部门卡片 → 部门详情弹窗 → 工作台账；风险/待汇报 → 任务详情/汇报提醒/任务督办；合同摘要 → 合同/开票/收款记录；重点专项 → **专项管理详情** |

**页面区块（P0）：**

| 区块 | 说明 | 优先级 |
| --- | --- | --- |
| **合同·开票·收款区（全量）** | 独立分组展示；**不随年度/季度筛选变化**；含回款率、累计开票、剩余收款 KPI 及明细/进度条 | P0 |
| **目标·计划·任务区（随筛选）** | 独立分组；筛选器（年/季/部门）**仅作用于本区**；含需关注目标、节点、计划、待汇报、风险、督办 KPI | P0 |
| 目标·计划·任务链路 | 年/季/月目标、计划、任务数量与状态摘要（随筛选变化） | P0 |
| 各部门达成 | 部门**健康分布**卡片（正常 X · 需关注 Y · 风险 Z），下钻弹窗含目标/计划/滞后任务（随筛选变化） | P0 |
| 重点专项 | 专项**节点达成 + 滞后任务**列表；点击跳转**专项管理详情大弹窗**（含关联计划与任务） | P0 |
| 风险与待办 | 滞后任务清单 + 待汇报人员清单（链汇报提醒；随筛选变化） | P0 |

**筛选与口径规则（P0）：**

| 规则 | 说明 |
| --- | --- |
| 分组展示 | 首屏 KPI **分两组**：① 合同/开票/收款（全量累计）；② 目标/计划/任务（经营执行） |
| 时间筛选范围 | 年度、季度、部门筛选**仅影响第二组**及下属链路、部门达成、风险待办 |
| 合同区口径 | 合同总数/总额、累计开票、回款、剩余收款等为**全量累计**，不受 Q1/Q2 等切换影响 |
| 任务区口径 | 需关注目标、进行中计划/任务、待汇报、督办等按所选**年/季/部门**聚合 |

> **已移除（v1.0.0）：** 经营总览页「工作汇报快照」横幅区块；周期快照仅在**工作周报**页查看（见 V1 工作周报）。

**正常流程：** 扫合同全量区掌握收付 → 切换年/季/部门看经营执行 KPI → 下钻部门或专项 → 跳转工作台/汇报提醒/合同收款/专项管理跟进。  
**边界情况：** 无合同时合同区空态；部门负责人文案仅本部门；切换筛选时合同区数值保持不变。  
**异常兜底：** 无目标数据时空态提示去新建目标。

#### 3.2 部门经营详情

| 维度 | 内容 |
| --- | --- |
| 功能介绍 | 展示某部门目标健康、计划节点进度、任务执行概况与跟进缺口 |
| 前置条件 | 从总览下钻或部门列表进入 |
| 数据权限 | 本部门数据；领导可看任意部门 |
| 页面跳转 | 目标行 → 目标详情；计划行 → 计划详情；任务入口 → 我的任务；「进入工作台」→ 工作台账 |

#### 3.3 项目经营详情

| 维度 | 内容 |
| --- | --- |
| 功能介绍 | 按项目查看关联目标任务与周期进展 |
| 前置条件 | 项目已建档且有关联任务 |
| 数据权限 | 项目所属部门成员可见；领导全量 |
| 页面跳转 | 任务名称 → 任务详情；可链至我的任务 |

## 4. 结算收款 · 合同开票收款

> 由 V1 主 PRD §4.8 迁出。


**业务链路（P0）：** 合同建档 → **开票记录**（登记已开发票）→ **收款记录**（登记实际到账）。开票与收款均**必须关联合同**；**开票与收款之间无强关联**（收款可不关联开票，无强制先后顺序）。

#### 4.1 合同管理

| 维度 | 内容 |
| --- | --- |
| 功能介绍 | 录入已签订合同；列表展示并统计**合同总数、合同总额、累计开票、回款总额、剩余收款** |
| 前置条件 | 客户主数据已在 **CRM** 维护；本模块仅选择客户，不维护客户档案 |
| 数据权限 | 商务/财务相关角色可写；领导可看汇总 |
| 页面跳转 | 新建/编辑/详情大弹窗；可跳转**开票记录**登记开票、**收款记录**登记收款 |

**摘要口径（P0）：**

| 指标 | 口径 |
| --- | --- |
| 合同总数 | 未作废合同条数 |
| 合同总额 | 合同金额合计 |
| 累计开票 | 状态为「已开票」的开票记录合计（**不含已作废**） |
| 回款总额 | 关联收款记录合计 |
| 剩余收款 | 合同总额 − 回款总额 |
| 待开票 | 合同总额 − 累计开票（按合同维度汇总；不含已作废发票） |

**业务规则：**

| 规则 | 说明 | 优先级 |
| --- | --- | --- |
| 客户选择 | 从 CRM 客户列表选择，禁止在本模块新建客户 | P0 |
| 剩余收款 | 合同总额 − 累计回款 | P0 |
| 超额回款 | 允许；保存时提示「累计回款将超过合同金额」 | P0 |
| 超额开票 | 允许；保存时提示「累计开票将超过合同金额」 | P0 |

**正常流程：** 选客户 → 填合同信息 → 保存 → 按需登记开票/收款（顺序不限）→ 摘要刷新。  
**边界情况：** 尚无开票/收款时对应指标为 0；允许先收款后开票、预收款不关联开票；已作废发票不计入累计开票。  
**异常兜底：** 编号重复、金额非法拦截。

#### 4.2 开票记录

| 维度 | 内容 |
| --- | --- |
| 功能介绍 | **必须关联合同**登记已开发票；记录发票号码、开票金额、开票日期、发票类型等 |
| 前置条件 | 至少存在一条合同 |
| 数据权限 | 同合同管理可写范围 |
| 页面跳转 | 登记开票弹窗；合同行/详情可带入合同；可跳转收款记录登记收款 |

**列表必显列（P0）：** 开票日期、发票号码、关联合同、客户、开票金额、发票类型、状态、操作（编辑 / 作废 / 登记收款；已作废仅展示不可操作）。

**摘要口径（P0）：**

| 指标 | 口径 |
| --- | --- |
| 累计开票 | 状态为「已开票」的记录合计（**不含已作废**；可按年筛选） |
| 本月开票 | 当前自然月有效开票合计 |
| 待开票 | 合同总额合计 − 累计开票 |
| 开票笔数 | 有效开票记录条数（不含已作废） |

**业务规则：**

| 规则 | 说明 | 优先级 |
| --- | --- | --- |
| 关联合同必选 | 未选合同不可保存 | P0 |
| 必填项 | 发票号码、开票金额、开票日期、发票类型 | P0 |
| 发票类型 | 增值税专用发票 / 增值税普通发票 | P0 |
| 超额提示 | 单笔导致合同累计开票 > 合同金额时强提示，仍可确认保存 | P0 |
| 发票作废 | 列表操作「作废」→ 二次确认 → **仅将状态标记为「已作废」**；不涉及红冲流程；已作废不计入累计开票/待开票 | P0 |

**正常流程：** 选合同 → 填发票信息与金额 → 保存 → 合同「已开票/待开票」更新；需作废时在列表操作标记状态。  
**边界情况：** 一合同多张发票；已作废发票保留记录、列表可筛「已作废」、不可再编辑或重复作废。  
**异常兜底：** 未选合同、金额≤0、缺发票号拦截。

#### 4.3 收款记录

| 维度 | 内容 |
| --- | --- |
| 功能介绍 | **必须关联合同**登记实际收款；**关联开票为选填**（开票与收款无强关联）；统计**本年计划收款、累计开票、累计收款、剩余收款** |
| 前置条件 | 至少存在一条合同 |
| 数据权限 | 同合同管理可写范围 |
| 页面跳转 | 登记收款弹窗；合同/开票行可带入合同；可回看合同详情 |

**摘要口径（P0）：**

| 指标 | 口径 |
| --- | --- |
| 本年计划收款 | **独立配置**年度计划金额，**不与合同自动关联加总** |
| 累计开票 | 与开票记录口径一致（展示于收款记录页摘要） |
| 累计收款 | 已登记收款合计（可按年筛选） |
| 剩余收款 | 合同总额合计 − 累计收款 |

**业务规则：**

| 规则 | 说明 | 优先级 |
| --- | --- | --- |
| 关联合同必选 | 未选合同不可保存 | P0 |
| 关联开票 | **选填**；下拉展示该合同下状态为「已开票」的发票；**不强制与开票绑定**，支持预收款、先收款后开票 | P1 |
| 本年计划独立配置 | 单独维护「本年度计划收款额」，不从合同汇总 | P0 |
| 超额提示 | 单笔导致合同累计回款 > 合同金额时强提示，仍可确认保存 | P0 |

**正常流程：** 配置本年计划（可选）→ 选合同登记收款（关联开票可不选）→ 合同回款/剩余更新。  
**边界情况：** 一合同多笔收款；预收款/先收款后开票时关联开票为空；开票作废后已关联的收款记录保留、不做级联处理。  
**异常兜底：** 未选合同、金额≤0 拦截。

### 4.4 弹窗交互（合同相关）

| 场景 | 交互 | 优先级 |
| --- | --- | --- |
| 合同 / 开票 / 收款新建 | 列表「新建」→ 标准居中弹窗 | P0 |
| 合同 / 开票 / 收款编辑 | 「编辑」→ 同表单回填 | P0 |
| 合同 / 开票 / 收款详情 | 点击名称 → 详情弹窗 | P0 |
| 禁止 | 本模块内维护 CRM 客户（客户选自 CRM） | P0 |

## 5. 经营计划 · 量化达成

| 维度 | 内容 | 优先级 |
| --- | --- | --- |
| 功能介绍 | 为目标维护**目标值 / 当前值**，展示达成进度与较上期趋势；反哺经营总览与目标列表 | P0 |
| 前置条件 | V1 目标主数据已存在；指标字典或手工录入规则已确认 | P0 |
| 数据权限 | 同目标可见范围；目标值维护权限【待确认】 | P0 |
| 页面跳转 | 目标列表/详情展示达成；经营总览可看汇总 | P0 |

| 规则 | 说明 | 优先级 |
| --- | --- | --- |
| 展示 | 支持当前值、目标值、达成比；**不替代**健康状态 | P0 |
| V1 关系 | V1 明确不做量化；本版启用后 V1 页面可按开关展示【待确认】 | P1 |
| 加总 | 下级目标值是否强制对齐上级【待确认】 | P1 |

**正常流程：** 配置目标值 → 周期更新当前值 → 总览/列表查看达成。  
**边界情况：** 未配置目标值时达成区空态。  
**异常兜底：** 当前值非法（负数等）拦截。

## 6. 生产作业（占位）

| 能力 | 说明 | 优先级 |

### 13.2 经营总览 KPI 口径


| KPI | 规则 | 优先级 |
| --- | --- | --- |
| **分组规则** | KPI 分两组：**合同/开票/收款**（全量，不随年/季变）与**目标/计划/任务**（随年/季/部门筛选变） | P0 |
| 关注目标数 | 健康状态 = 关注 的目标计数 | P0 |
| 滞后任务 | 当前日期 > 结束日期且业务状态≠已完成；或连续 2 个填报周期未更新 | P0 |
| 待汇报 | 本周期应填但未提交进展的任务对应人数 | P0 |
| 本周到期关键节点 | 节点日期落在本周（自然周周一至周日）且未完成 | P0 |
| 部门健康分布 | 按部门汇总目标健康：正常 X · 关注 Y（工作台账对照表另含计划/任务完成延期） | P0 |
| 合同回款率 | 回款总额 / 合同总额（沿用合同模块口径） | P0 |
| 累计开票 | 状态为「已开票」的开票记录合计（**不含已作废**）；经营总览 KPI 卡与摘要区展示 | P0 |
| 待开票 | 合同总额 − 累计开票（不含已作废） | P0 |
