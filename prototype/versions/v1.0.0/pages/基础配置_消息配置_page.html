消息配置 v1.0.0

配置任务未填催办、计划按紧急程度临期提醒；触达模拟企微个人消息。规则即时生效于「催办提醒」。目标/计划另支持业务页手动催办。

组织 · 催办触达对象

沿用上版「部门 → 部门负责人」映射；催办发给对应负责人（仅已启用部门参与扫描）

部门 负责人 岗位 使用范围

任务管理 · 未填催办

按自然周扫描：该部门本周无任何任务记录 → 催办部门负责人

占位符：{姓名} {部门} {周次}

计划管理 · 临期催办

按紧急程度配置「距结束日剩余天数」；命中则提醒计划所属部门负责人（完成%≥100 或已过期不催）

逗号分隔，剩余天数命中即提醒

占位符：{姓名} {计划} {紧急程度} {结束日期} {剩余天数}
